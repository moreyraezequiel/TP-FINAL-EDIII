# Librería de drivers

`CMSISv2p00_LPC17xx/` es una copia de la librería de drivers de la cátedra:

- Origen: <https://github.com/David-A-T-M/LPC17xx-CMSIS-Driver-Enhancement>
- Versión copiada: commit `511893e` (5/3/2026).
- Licencia: BSD-3-Clause (código original de NXP y modificaciones de David Trujillo Medina).

Está incluida en el repositorio para que todos compilen con la misma versión. Es un proyecto de
librería de MCUXpresso: se importa al workspace sin copiarlo (ver `firmware/README.md`).

**No modificar los archivos acá.** Para actualizarla, volver a copiar la carpeta desde el
repositorio original y anotar el commit nuevo en este archivo.
